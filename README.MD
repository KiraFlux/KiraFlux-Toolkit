# KiraFlux Toolkit

Библиотека компонентов для embedded-разработки на ESP32 (Arduino).  
Предоставляет графику, пользовательский интерфейс, драйверы устройств, контроллеры драйверов, математические утилиты и сетевое взаимодействие.

## Основные компоненты

- **Графика** - `Canvas`, драйверы дисплеев (`SSD1306`, `ST7735`), шрифты, работа с изображениями.
- **Пользовательский интерфейс** - виджеты, страницы, навигация, поддержка различных рендереров (включая текстовый).
- **Ввод** - джойстики, кнопки, энкодеры с фильтрацией и калибровкой.
- **Драйверы** - моторы, сервоприводы, датчики (Sharp, энкодеры).
- **Контроллеры** - 2DOF манипулятор, мотор-энкодер (WIP) 
- **Сеть** - ESP-NOW с удобной C++ обёрткой, протокол `MizLangBridge` для структурированной коммуникации.
- **Математика** - векторы (`vec2`, `vec3`), фильтры (EMA, комплементарный, низкочастотный), PID-регулятор, таймеры.
- **Утилиты** - `Option`/`Result` (без исключений), `StringView`, `ArrayString`, слайсы, логгер, валидация.

## Поддерживаемые платформы

- ESP32 (среда Arduino)
- Минимальный стандарт C++17

## Быстрый старт

### PlatformIO

Добавьте в `platformio.ini` вашего проекта:

```ini
lib_deps = https://github.com/KiraFlux/KiraFlux-Toolkit.git
```
